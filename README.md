# Library Helper (Standalone)

grill-me(AI対話)で今の自分に合う本を探し、読みながらAI司書と対話し、気になったフレーズを読書録に残せる、ブラウザだけで動く個人用の読書サポートアプリです。

AIには **あなた自身のGemini APIキー**(BYOK: Bring Your Own Key)を使います。

> **カスタマイズせず使うだけなら、こちらのURL版を利用できます**: https://library-helper-standalone.vercel.app/
> インストール不要で、すぐに使い始められます(下記のGemini APIキー設定だけ行ってください)。

## 主な機能

- **grill-me**: AI司書(オランジェ/ゲルプ)との対話から、悩みや好みに合わせて3冊を選書
- **トレンド・著者探訪**: カテゴリや著者名から本を探す
- **読書支援**: 読み始めた本について、AI司書と対話しながら読書を進められる
- **熱血プレゼン**: 選ばれた本の魅力を長文で紹介
- **読書録**: 気になったフレーズや読書状態(読書中/完読/中断)をブラウザ内に保存

## URL版の使い方

1. 配布されたURLをブラウザで開く
2. 右上の鍵アイコンをクリック
3. 自分のGemini APIキーを貼り付けて「保存」
4. あとは自由に使えます(インストール・登録は不要)

## Gemini APIキーの取得方法

1. [Google AI Studio](https://aistudio.google.com/apikey) にアクセスし、Googleアカウントでログイン
2. 「APIキーを作成」からキーを取得
3. 取得したキーをコピーし、本アプリの設定画面に貼り付け

## APIキーの保存方式(BYOK)について

- 入力したキーは、**あなたのブラウザのlocalStorageにのみ**保存されます
- AI機能(grill-me・読書支援・意味質問・選書・著者探訪・熱血プレゼン)を使うときだけ、保存されたキーが**Library Helperのサーバーを一時的に経由して**Gemini APIへ送信されます
- Library Helper側では、APIキーをデータベース・ファイル・アプリケーションログに永続保存しません。APIリクエスト処理のために一時的に使用します。
- キーはブラウザ単位・端末単位の保存です。別のブラウザ・別の端末では再度設定が必要です

## 共有端末で使う場合の注意

職場のPCや家族共有のPCなど、自分専用ではない端末で使う場合は、**利用後に設定画面の「削除」ボタンでキーを消してから**離れてください。保存したままにすると、同じ端末・ブラウザを使う他の人からキーが読み取れる状態になります。

## ローカルで動かす場合

事前にNode.jsとnpmが必要です(未インストールの場合は [nodejs.org](https://nodejs.org/) から導入してください)。

```bash
git clone https://github.com/tamak0lab-jpg/library-helper-standalone.git
cd library-helper-standalone
npm install
npm run dev
```

ブラウザで `http://localhost:3000/app` を開いてください。

## 環境変数の設定は不要です

.envファイルの作成やGemini APIキーの環境変数設定は必要ありません。利用者自身のAPIキーをアプリの設定画面から登録するBYOK方式です。

## 書籍検索について(Google Books)

本の検索にはGoogle Books APIを匿名利用しています。短時間に多くの検索が行われると、一時的に「候補が見つからない」等のエラー(429)になることがあります。その場合は少し時間を置いてから再度お試しください。
